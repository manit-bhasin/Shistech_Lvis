Emergency mesh

Click anywhere on the map to send an SOS from a home unit at that spot. It reaches the nearest relay over ESP-NOW, then hops relay to relay over LoRa until it reaches the rescue base in the centre.

    About this demo

    Nodes follow the same rules as the project's Python simulator (simulation/meshsim/node.py): duplicate dropping, a hop limit of 6, highest priority sent first, a random wait of up to 1 s before sending, a confirmation from the base, and up to 5 sends with doubling waits from 90 s. The 25-node layout is the same one used in the Python demo.

    Simplified for clarity: radio collisions, listen-before-talk and random packet loss are left out here; the Python simulator models all three. Radio range is 800 m (assumed from published figures, not measured) and home unit reach is 200 m (assumed, not measured). The base sees each node's recorded location and the typed landmark, not the exact spot that was clicked.
